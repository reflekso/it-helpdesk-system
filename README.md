Добро пожаловать в репозиторий проекта **IT Helpdesk System**. 

Данный проект представляет собой полноценную систему управления заявками в IT-поддержку. Репозиторий выступает в качестве **портфолио системного аналитика** и демонстрирует полный цикл проектирования программного обеспечения: от выявления бизнес-требований и моделирования процессов до детальной проработки архитектуры, API-контрактов и структуры базы данных.

## Цель проекта
Создать понятный, масштабируемый и удобный сервис для взаимодействия сотрудников компании с отделом IT-поддержки. 

С точки зрения аналитики, проект призван продемонстрировать навыки работы с современными практиками и инструментами проектирования информационных систем.

## Технологический стек проекта
Несмотря на то, что фокус данного репозитория смещен на аналитику, проект спроектирован под следующий технический стек:
* **Frontend:** React + TypeScript + Vite
* **Backend:** Go
* **Database:** PostgreSQL
* **Интеграции:** REST API, OpenAPI 3.1
* **Документация и моделирование:** BPMN, C4 Model, ER-диаграммы, User Flows

## Ключевые компетенции (Hard Skills), продемонстрированные в проекте:
- **Сбор и анализ требований:** Формирование бизнес-, пользовательских и системных требований.
- **Нотации моделирования:** Описание бизнес-процессов с использованием BPMN.
- **Архитектурный дизайн:** Использование методологии C4 для визуализации архитектуры приложения.
- **Проектирование API:** Разработка спецификаций RESTful API с использованием Swagger/OpenAPI.
- **Моделирование данных:** Проектирование реляционных баз данных, построение ER-моделей.
- **UX/UI Аналитика:** Построение Use Cases и User Flows.
